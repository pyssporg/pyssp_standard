# DEC-IMP019-R1-001: SSP FMU Iteration API Surface

- **Status:** Active
- **Date:** 2026-05-26
- **Context:** Need a safe, lazy API to iterate FMU-backed components inside an SSP. Three options evaluated: A (eager property), B (generator on SSP), C (standalone helper).
- **Decision:** Hybrid B+C. `FmuEntry` dataclass with `open_fmu()`, standalone `iter_fmu_entries()` in operations layer, thin `SSP.iter_fmu_entries()` facade.
- **Consequences:**
  - Operations-layer function testable without SSP artifact
  - `FmuEntry.open_fmu()` shifts lifecycle to caller (expected pattern)
  - `skip_missing=True` by default for safety
  - `skip_missing=False` for power users
  - Extensible with filtering in future
